# TASK 9 – Evaluate Memory Hierarchy and I/O Systems

## Objective

To evaluate the memory hierarchy and different I/O techniques used in operating systems and understand their impact on system performance.

## Concept Details

This task covers the following concepts:

1. Memory Hierarchy
2. Registers
3. Cache Memory
4. Main Memory (RAM)
5. Secondary Storage (SSD and HDD)
6. Network Storage
7. Programmed I/O (PIO)
8. Interrupt-Driven I/O
9. Direct Memory Access (DMA)

## Memory Hierarchy

| Memory Type     | Description                               |
| --------------- | ----------------------------------------- |
| Registers       | Fastest storage located inside the CPU    |
| Cache           | Stores frequently accessed data           |
| RAM             | Holds currently running programs and data |
| SSD             | Provides fast permanent storage           |
| HDD             | Provides large-capacity permanent storage |
| Network Storage | Allows data access over a network         |

## I/O Techniques Comparison

| Technique            | Description                                                            |
| -------------------- | ---------------------------------------------------------------------- |
| Programmed I/O       | CPU continuously checks device status and manages data transfer        |
| Interrupt-Driven I/O | Device interrupts the CPU when it requires attention                   |
| DMA                  | Transfers data between devices and memory with minimal CPU involvement |

## Application in a Smart Hospital

* MRI images require high-capacity storage and efficient data transfer.
* Patient records require reliable storage and secure access.
* Bedside monitor readings require fast processing and timely responses.
* DMA can improve the transfer of large medical image files.

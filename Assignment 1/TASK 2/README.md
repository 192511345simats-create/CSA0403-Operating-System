# TASK 2 – Judge the Type of Operating System for Each Environment

## Objective

To compare different types of operating systems and identify the most suitable OS for each computing environment in a smart hospital.

## Contents

1. Comparison of mainframe, desktop, multiprocessor, distributed, clustered, real-time and handheld operating systems.
2. Selection of suitable OS types for hospital monitors, tablets, workstations, database servers, MRI servers and partner hospital communication.
3. Symmetric and asymmetric multiprocessing comparison.
4. Clustered database system with fail-over.
5. Alternative concept and complexity analysis.

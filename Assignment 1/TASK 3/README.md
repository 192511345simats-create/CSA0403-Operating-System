# TASK 3 – Evaluate Operating-System Structures

## Objective

To evaluate different operating-system structures and identify the most suitable structures for the smart hospital.

## Contents

1. Comparison of monolithic, layered, microkernel, modular and hybrid structures.
2. Evaluation of reliability, performance and ease of updating.
3. Selection of suitable structures for bedside patient monitors and the central database server.
4. Explanation of the structures used by Linux, Windows, Android and real-time operating systems such as FreeRTOS or QNX.
5. Alternative concept and complexity analysis of using a monolithic kernel instead of a microkernel for bedside monitors.

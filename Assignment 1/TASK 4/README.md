# TASK 4 – Evaluate the Services an Operating System Must Provide

## Objective

To evaluate the operating-system services required by different computing environments in a smart hospital.

## Contents

1. Evaluation of user interface, program execution, I/O operations and file-system services.
2. Communication, error detection, resource allocation and accounting services.
3. Protection and security services.
4. Identification of services that can be removed from bedside patient monitors.
5. Essential operating-system services required by the central database server.
6. Explanation of how the OS protects patient records from unauthorised access.
7. Alternative concept and complexity analysis of using a full desktop OS instead of a reduced handheld OS.

## Files

* Task04_Answer.pdf – Complete written answer and OS service evaluation.

## Conclusion

This task evaluates the essential and optional operating-system services for different hospital environments, considering performance, memory, battery life and security.

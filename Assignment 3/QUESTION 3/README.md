# Q3 – Segmentation

**Aim:** To implement segmentation and understand logical-to-physical address translation using a segment table.

**Requirements:**

* OS: Ubuntu 18.04.3
* Language: C
* Compiler: GCC

**File:**

* `segmentation.c`

**Compilation and Execution:**

```bash
gcc segmentation.c -o segmentation
./segmentation
```

**Concepts Covered:**

* Segmentation
* Segment Table
* Address Translation
* Memory Protection
* Segmentation Fault

**Result:** Segment-based address translation and memory protection were demonstrated.

**Conclusion:** Segmentation provides logical memory organization and protection for different program segments.

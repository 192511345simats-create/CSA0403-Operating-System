# Q2 – Paging

**Aim:** To implement paging and understand logical-to-physical address translation and page-table operations.

**Requirements:**

* OS: Ubuntu 18.04.3
* Language: C
* Compiler: GCC

**File:**

* `paging.c`

**Compilation and Execution:**

```bash
gcc paging.c -o paging
./paging
```

**Concepts Covered:**

* Paging
* Page Tables
* Address Translation
* Internal Fragmentation
* TLB
* Page Faults

**Result:** Paging and logical-to-physical address translation were implemented and studied.

**Conclusion:** Paging eliminates external fragmentation and provides efficient memory management.

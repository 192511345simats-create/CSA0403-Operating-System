# Q4 – Virtual Memory and Demand Paging

**Aim:** To study virtual memory, demand paging, page faults and copy-on-write using C programs.

**Requirements:**

* OS: Ubuntu 18.04.3
* Language: C
* Compiler: GCC

**Files:**

* `memory_access.c`
* `cow.c`

**Compilation and Execution:**

```bash
gcc memory_access.c -o memory_access
./memory_access
```

```bash
gcc cow.c -o cow
./cow
```

**Concepts Covered:**

* Virtual Memory
* Demand Paging
* Page Faults
* Copy-on-Write
* Thrashing
* Working Set Model

**Result:** Virtual memory and demand paging concepts were studied using C programs.

**Conclusion:** Demand paging allows programs to use memory efficiently by loading pages only when required.

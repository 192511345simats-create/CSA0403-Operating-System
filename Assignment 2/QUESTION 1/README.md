# Q1 – Processes and Process States

This folder contains the implementation and documentation of process management and process states in Operating Systems. It includes the process-state diagram, Process Control Block (PCB) explanation, and a C program demonstrating process creation using the `fork()` system call.

The program is used to understand parent and child processes, process identification, and process information using Linux commands.

**Files Included:**

* `Q1_Answer.pdf` – Detailed explanation and answers.
* `process.c` – C program for process creation.
* `output.png` – Screenshot of program execution.
* `README.md` – Project description and execution instructions.

# Q5 – Synchronisation: Critical Sections, Semaphores and Monitors

This folder contains the implementation and analysis of process synchronisation techniques in Operating Systems. It covers the critical-section problem, Peterson's solution, binary and counting semaphores, and monitors.

It also includes a C program demonstrating the Producer-Consumer problem using semaphores and mutex locks, ensuring proper synchronisation and preventing race conditions during concurrent execution.

**Files Included:**

* `Q5_Answer.pdf` – Detailed explanation and synchronisation analysis.
* `producer_consumer.c` – C program implementing the Producer-Consumer problem.
* `output.png` – Screenshot of program execution.
* `performance_results.txt` – Synchronisation performance comparison.
* `README.md` – Project description and execution instructions.

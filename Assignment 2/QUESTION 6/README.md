# Q6 – Deadlock Handling and Banker's Algorithm

This folder contains the implementation and analysis of deadlock-handling techniques in Operating Systems. It covers the four necessary conditions for deadlock, resource-allocation graphs, deadlock prevention, avoidance, detection, and recovery.

It also includes a C program implementing the Banker's Algorithm to check system safety, determine safe sequences, and evaluate resource-allocation requests.

**Files Included:**

* `Q6_Answer.pdf` – Detailed explanation and deadlock analysis.
* `banker.c` – C program implementing the Banker's Algorithm.
* `output.png` – Screenshot of program execution.
* `performance_results.txt` – Safety algorithm performance comparison.
* `README.md` – Project description and execution instructions.

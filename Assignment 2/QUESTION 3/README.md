# Q3 – Threads

This folder contains the implementation and analysis of multithreading concepts in Operating Systems. It explains thread creation, thread models, shared and private resources, and race conditions.

It also includes a C program using POSIX threads (`pthreads`) to demonstrate concurrent execution and an analysis of thread performance, speedup, and the advantages of using thread pools.

**Files Included:**

* `Q3_Answer.pdf` – Detailed explanation and analysis of threads.
* `threads.c` – C program demonstrating multithreading.
* `output.png` – Screenshot of program execution.
* `performance_results.txt` – Thread performance and speedup comparison.
* `README.md` – Project description and execution instructions.

# Q2 – CPU Scheduling

This folder contains the implementation and analysis of CPU scheduling algorithms used in Operating Systems. It covers FCFS, SJF, SRTF, Priority Scheduling, and Round Robin scheduling, including Gantt charts and the calculation of waiting time, turnaround time, and response time.

It also includes a C program demonstrating the Round Robin scheduling algorithm and an analysis of different time quantum values, starvation, and scheduling performance.

**Files Included:**

* `Q2_Answer.pdf` – Detailed explanation and scheduling calculations.
* `round_robin.c` – C program implementing Round Robin scheduling.
* `output.png` – Screenshot of program execution.
* `performance_results.txt` – Comparison of scheduling performance.
* `README.md` – Project description and execution instructions.

# Q4 – Inter-Process Communication (IPC)

This folder contains the implementation and analysis of Inter-Process Communication (IPC) techniques in Operating Systems. It explains communication between processes using pipes, shared memory, and message queues.

It also includes a C program demonstrating communication between a parent and child process using pipes, along with an analysis of data transfer, synchronization, and the differences between shared-memory and message-passing methods.

**Files Included:**

* `Q4_Answer.pdf` – Detailed explanation and IPC analysis.
* `ipc_pipe.c` – C program demonstrating communication using pipes.
* `output.png` – Screenshot of program execution.
* `performance_results.txt` – IPC data-transfer performance comparison.
* `README.md` – Project description and execution instructions.

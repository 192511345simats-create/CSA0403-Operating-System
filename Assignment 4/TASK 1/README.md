**Name:**
**Register Number:**
**Course:** CSA04 – Operating Systems
**Assignment:** CO4 – Assignment 4

## Objective

To evaluate an existing file-system design and suggest improvements in directory organisation, file allocation, naming rules and access control.

## Concepts Used

* Hierarchical directory structure
* File naming conventions
* File attributes
* Access control and permissions
* Indexed allocation
* Backup and recovery

## Design

A hierarchical directory structure is proposed to organise student files department-wise and student-wise. Access permissions protect individual files, while shared project folders allow authorised collaboration.

## Result

The proposed design improves file organisation, reduces naming conflicts, provides better privacy and supports secure file sharing.
